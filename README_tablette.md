# États des lieux — guide tablette

Application pour relever l'état des 14 communes déléguées de Noyant-Villages avec les maires délégués.
Elle fonctionne **sans connexion** et **toutes les données restent sur la tablette**.

Adresse de l'application : **https://cjayconseil-max.github.io/edl-noyant/**

## 1. Installer sur la Galaxy Tab S9 (une seule fois, avec le Wi-Fi)

1. Ouvrez **Chrome** sur la tablette et saisissez l'adresse ci-dessus.
2. Touchez le menu **⋮** en haut à droite, puis **« Installer l'application »** (ou « Ajouter à l'écran d'accueil »), puis **Installer**.
3. L'icône **EDL Noyant** apparaît sur l'écran d'accueil. Ouvrez toujours l'application par cette icône.
4. À la première photo, répondez **Autoriser** pour l'appareil photo, et **Autoriser** pour la position si vous voulez les coordonnées GPS sur les photos. Un refus ne bloque rien.

## 2. Vérifier le mode hors connexion (avant la première tournée)

1. Ouvrez l'application une fois avec le Wi-Fi.
2. Activez le **mode Avion**, fermez l'application, rouvrez-la.
3. Elle doit s'afficher normalement, avec la mention **« Hors connexion »** en haut.

## 3. Pendant la visite

- **Communes** : touchez la tuile de la commune. Les boutons du haut filtrent par secteur.
- **Visite** : statut, date, participants, synthèse. Tout s'enregistre tout seul à chaque saisie.
- **Relevés** : domaine, lieu, point vérifié, état (4 gros boutons de couleur), priorité, constat, action, coût.
  - **Prendre une photo** ouvre l'appareil photo arrière. Vous pouvez ensuite dessiner au doigt une **flèche** ou un **cercle** rouge, puis **Enregistrer la photo**. La commune, le lieu, la date et l'heure sont inscrits en bas de l'image.
  - Saisissez le lieu **avant** de prendre la photo pour qu'il figure dessus.
  - Terminez par **Enregistrer le relevé**. Si l'application se ferme avant, la saisie est retrouvée telle quelle (« Brouillon repris »).
- **Demandes** : notez la demande du maire délégué, puis changez son statut et saisissez la réponse plus tard.
- **Suivi** : tableau de tous les relevés ou de toutes les demandes, avec filtres.

## 4. Sauvegarder et envoyer (onglet Export)

- **Archive complète** : un fichier .zip avec le classeur Excel et toutes les photos. **À faire après chaque journée de visites**, par exemple vers votre messagerie ou OneDrive avec le bouton Partager.
- **Classeur Excel** : même présentation que `Etats_des_lieux_Noyant-Villages.xlsx` (Synthèse, Relevés, Demandes, Listes).
- **Compte rendu PDF** : un document par commune, avec les photos, à envoyer au maire délégué.
- Un bandeau jaune sur l'accueil vous rappelle d'exporter si rien n'a été sauvegardé depuis 7 jours.

## 5. Reprendre un classeur modifié sur ordinateur

Onglet **Export** → **Importer un classeur Excel**. Un aperçu compare la tablette et le fichier ; rien n'est remplacé avant que vous touchiez **« Remplacer les données de la tablette »**.

- Les photos sont retrouvées par leur nom dans la colonne « Photos » : ne modifiez pas cette colonne sur ordinateur.
- Les participants d'une visite ne figurent pas dans le classeur : ils restent sur la tablette et dans le PDF.

## À savoir

- **Ne videz pas les données de Chrome** et ne désinstallez pas l'application sans avoir fait une archive complète : relevés et photos seraient perdus.
- Les noms des maires délégués se modifient dans la fiche commune, onglet Visite, « Modifier les informations de la commune ».
- Affichage clair ou sombre et GPS : onglet Export, rubrique Réglages.
